# Relay

เว็บแอปบนเครื่องสำหรับสั่งงาน Codex, Claude Code และ Gemini ผ่าน Git repo เดียวกัน เปิดที่ [http://127.0.0.1:4782](http://127.0.0.1:4782)

## เปิดใช้งานบน Windows

ใช้ Node.js 22.13 ขึ้นไปและ Git จากนั้นรันใน PowerShell

```powershell
Set-Location D:\AI\relay
npm.cmd ci
npm.cmd run build
npm.cmd start
```

ถ้าติดตั้ง dependencies และ build มาแล้ว เปิดแอปซ้ำด้วย `npm.cmd start` ได้เลย

## เชื่อมต่อ AI

| ผู้ให้บริการ | ตั้งค่า | ข้อมูลโควตา |
| --- | --- | --- |
| Codex | ลงชื่อเข้าใช้ ChatGPT ใน Codex บนเครื่อง แอปลองใช้ CLI ที่มากับ Codex บน Windows ก่อน จากนั้นใช้ `codex` บน PATH หรือพาธจาก `RELAY_CODEX_BIN` | อ่านหน้าต่างโควตาและเวลารีเซ็ตจาก Codex App Server |
| Claude Code | ติดตั้ง Claude Code (`irm https://claude.ai/install.ps1 \| iex`) แล้วรัน `claude auth login` ด้วยบัญชี claude.ai แอปหา `claude.exe` ใน `%USERPROFILE%\.local\bin` ก่อน จากนั้นใช้ `claude` บน PATH หรือพาธจาก `RELAY_CLAUDE_CODE_BIN` Relay ไม่ส่ง `ANTHROPIC_API_KEY` ให้ จึงใช้โควตาจาก subscription | ตรวจสถานะลงชื่อเข้าใช้ด้วย `claude auth status` Claude Code ไม่เปิดเผยโควตาที่เหลือ ถ้าเจอข้อความว่าโควตาเต็ม Relay จะพักตัวนี้ 15 นาที |
| Gemini | ใช้ `GEMINI_API_KEY` หรือ `GOOGLE_API_KEY` ใน environment หรือไฟล์ `.env` | ตั้งเพดานคำขอต่อวันตาม AI Studio แอปประมาณจากคำขอที่ส่งผ่าน Relay และรีเซ็ตตามเวลา Pacific |

ดูตัวอย่างตัวแปรใน `.env.example` แล้วเริ่มเซิร์ฟเวอร์ใหม่หลังแก้ไฟล์ `.env` API keys ใช้อยู่ที่เซิร์ฟเวอร์บนเครื่อง

## สร้างงาน

1. ที่หน้า **ตั้งค่า** เลือก AI ตัวหลักและตัวสำรองสำหรับแต่ละขั้น ตั้งโควตาที่กันไว้สำหรับรีวิว และกำหนดจำนวนรอบส่งกลับไปแก้
2. กด **สร้างงาน** ใส่พาธแบบเต็มของ Git repo ที่มี commit และระบุเกณฑ์รับงาน แอปเริ่มจาก HEAD และส่งโจทย์พร้อมไฟล์โค้ดที่ commit แล้วบางส่วนไปยังผู้ให้บริการที่ถูกเลือก ไฟล์ที่ยังแก้ค้างใน checkout ปัจจุบันจะไม่ถูกนำเข้า
3. ดูประวัติว่าใครรับงานและทำไมถึงข้ามตัวหลัก แอปลองตัวสำรองเมื่อ AI ไม่พร้อม โควตาถึงระดับที่กันไว้ หรือคำขอล้มเหลว ถ้าไม่มีตัวพร้อม งานจะแจ้งว่าติดขัดและให้สร้างงานใหม่จากโจทย์เดิมได้
4. เปิด **Git diff** และดูผลรีวิวในหน้างาน ผลรวมยังอยู่บน branch `relay/<id>` ใน worktree แยก คุณเลือก merge เองผ่าน Git ได้ หากเกิด conflict ให้ตรวจจาก branch ของ Backend และ UX/UI ที่ระบุในประวัติงาน

ถ้าเลือกให้ทดสอบ แอปจะรันสคริปต์ `test` และ `build` ที่มีใน `package.json` ที่ root หากมี dependencies แอปใช้ `npm ci --ignore-scripts` เพื่อเตรียมจาก lockfile สคริปต์ของ repo รันบนเครื่อง จึงควรใช้ตัวเลือกนี้กับ repo ที่ไว้ใจ

เวอร์ชันนี้รองรับการเพิ่มและแก้ไฟล์ข้อความจาก snapshot ขนาดจำกัด งานที่ต้องลบไฟล์ สร้างไฟล์ไบนารี หรือใช้ context ทั้ง repo ขนาดใหญ่อาจต้องแก้ต่อจาก branch ผลลัพธ์ คิวและประวัติเก็บใน `.relay/state.json` และ worktree ผลลัพธ์อยู่ใต้ `.relay/worktrees` การปิดเซิร์ฟเวอร์ระหว่างรันจะเก็บ commit ที่ทำเสร็จแล้วและแสดงงานเป็นถูกขัดจังหวะเมื่อเปิดใหม่

Claude Code ทำงานแบบอ่านอย่างเดียวใน worktree ของงาน (ใช้ได้แค่เครื่องมือ Read, Glob และ Grep) แล้วส่งผลกลับเป็น JSON ให้ Relay เขียนไฟล์และ commit เอง โหมดนี้ใช้บัญชี claude.ai ของคุณ จึงเหมาะกับการใช้งานส่วนตัวบนเครื่องของคุณ Relay ไม่เรียก Claude API โดยตรงและไม่ส่ง `ANTHROPIC_API_KEY` ให้ Claude Code จึงไม่มีค่าใช้จ่ายตาม API เพิ่ม
